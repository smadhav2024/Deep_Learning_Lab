# Comparative Study of Deep CNN Architectures Using Transfer Learning

**CS3807 – Deep Learning Laboratory, Experiment 4 - Transfer Learning (VGG16)**

A transfer-learning pipeline built with TensorFlow/Keras that adapts a pretrained VGG16
(ImageNet weights) to classify CIFAR-10 images into 10 categories, followed by fine-tuning
and a hyperparameter study.

## Overview

This project covers the full pipeline end to end:

- A written comparison of deep CNN architecture evolution (LeNet-5, AlexNet, VGG16,
  GoogleNet, ResNet), plus short runnable demos of dilated and transpose convolution
- Dataset exploration (sample images, dimension checks) and a `tf.data` input pipeline
  (on-the-fly resize to $96\times96$ + $[0,1]$ normalization, so nothing needs to fit in
  memory as raw NumPy arrays)
- A VGG16-based transfer learning model - frozen convolutional base + GlobalAveragePooling
  $\to$ Dense(256, ReLU) $\to$ Dropout $\to$ Dense(10, Softmax) - with full epoch-by-epoch
  training logs
- Fine-tuning of the last convolutional block (`block5`) at a low learning rate, with a
  direct before/after accuracy comparison
- Evaluation (accuracy, precision, recall, F1-score, confusion matrix, classification report)
- A hyperparameter study covering all six settings from the lab manual - learning rate,
  optimizer, dense units, batch size, epochs, and frozen vs. partial unfreezing
- All 10 discussion questions from the lab manual, answered directly

## Results

| Metric               | Frozen Base | Fine-Tuned |
|-----------------------|-------------|------------|
| Test Accuracy          | 71.11%      | 83.22%     |
| Test Loss              | 0.8382      | 0.5110     |

| Metric    | Value (Fine-Tuned) |
|-----------|---------------------|
| Precision | 83.28%              |
| Recall    | 83.22%              |
| F1-score  | 83.12%              |

Fine-tuning `block5` improved test accuracy by **+12.11 percentage points** over the
frozen-base model. Out of 10,000 test images, 1,678 were misclassified, concentrated
heavily around the cat/dog pair (183 cats predicted as dogs, 91 dogs predicted as cats -
by far the two largest off-diagonal values in the confusion matrix).

## Dataset

**CIFAR-10 Dataset** — University of Toronto, fetched programmatically via
`tensorflow.keras.datasets.cifar10`, so no manual download is required.

- 60,000 colour images total (50,000 train / 10,000 test), $32 \times 32$ pixels, RGB,
  10 object classes (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck)
- Classes perfectly balanced (5,000 training images per class)
- No missing values
- Images are resized on the fly to $96\times96$ before being passed through VGG16, since
  the native $32\times32$ resolution collapses to a $1\times1$ feature map after VGG16's
  five pooling layers, leaving very little for Global Average Pooling to work with

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

```bash
jupyter notebook deep_learning_lab_4.ipynb
```

or open it directly in [Google Colab](https://colab.research.google.com/) (GPU runtime
strongly recommended - VGG16 at $96\times96$ input is noticeably heavier than a from-scratch
CNN on native $32\times32$ CIFAR-10) and run all cells top to bottom. The notebook fetches
the dataset and pretrained ImageNet weights itself - nothing needs to be downloaded by hand.
