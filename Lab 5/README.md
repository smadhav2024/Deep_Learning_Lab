# Comprehensive Study of CNN Training, Regularization, Optimization, Hyperparameter Tuning, Transfer Learning and Cross-Validation

**CS3807 – Deep Learning Laboratory, Experiment 5 - MobileNetV2 on Oxford-IIIT Pet**

A single CNN architecture, MobileNetV2, used throughout to systematically study weight
initialization, regularization, optimizers, hyperparameter tuning, transfer learning and
fine-tuning, and 5-fold cross-validation for model selection, on the Oxford-IIIT Pet dataset
(37 cat and dog breeds).

## Overview

This project covers the full pipeline end to end:

- Dataset loading via `tensorflow_datasets` (7,349 images, 37 breeds), stratified into a
  70/15/15 train/validation/test split, with the test set held out untouched until the
  very last evaluation
- Weight initialization comparison (Zero, Random, Xavier/Glorot, He) on the frozen-base
  classifier head, directly demonstrating Zero initialization's symmetry-breaking failure
- Regularization comparison (No regularization, L2, Dropout, Batch Normalization) with
  training/validation curves showing the generalization gap
- A worked numerical example of Batch Normalization, plus a With-BN vs. Without-BN
  head-to-head comparison
- Optimizer comparison (SGD, Momentum, RMSProp, Adam) with convergence speed and time
- Hyperparameter sweeps (learning rate, batch size, dropout rate), one setting varied at a
  time
- Transfer learning via MobileNetV2 - frozen feature extraction, then fine-tuning the last
  30 layers at a much lower learning rate
- 5-fold cross-validation across 4 candidate configurations, selecting the final model on
  both mean accuracy and consistency (standard deviation), not just the single highest score
- Final model evaluation on the untouched test set (accuracy, precision, recall, F1-score,
  confusion matrix, misclassified images)
- All 23 discussion questions from the lab manual, answered directly
- An additional exercise testing two new hyperparameter combinations via 5-fold CV against
  the selected configuration

## Results

| Metric | Value |
|--------|-------|
| Selected Configuration | C3: RMSProp, Dropout 0.5, Batch Normalization |
| Mean CV Accuracy | 91.52% |
| CV Standard Deviation | 0.24 |
| Test Accuracy | 90.03% |
| Precision (macro) | 0.9021 |
| Recall (macro) | 0.9002 |
| F1-score (macro) | 0.8997 |
| Training Time | 87.1 s |
| Parameters | 2,431,845 |

The final configuration (C3) was chosen over several individually higher-scoring single-run
results - Best Hyperparameters reached 92.47% and Best Initialization reached 92.11% on their
own validation splits - because C3 was the only configuration validated for both accuracy
*and* consistency across five independent folds, rather than a single lucky split. Zero
initialization failed completely (2.7%, random-guess level among 37 classes), directly
demonstrating the classic symmetry-breaking problem. Two additional configurations tested via
the same 5-fold process (Additional Exercise) both fell short of C3, confirming it as the
preferred choice.

## Dataset

**Oxford-IIIT Pet Dataset** — loaded programmatically via `tensorflow_datasets`
(`oxford_iiit_pet`), so no manual download is required.

- 7,349 RGB images total, spanning 37 cat and dog breeds
- Resized to $224 \times 224 \times 3$ and normalized using MobileNetV2's own
  `preprocess_input`, matching the ImageNet statistics the pretrained base expects
- Stratified 70/15/15 split: 5,144 training / 1,102 validation / 1,103 test images
- Test set kept completely untouched until the final evaluation stage - every earlier
  section, including the 5-fold cross-validation, used only the training split

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

```bash
jupyter notebook Deep_Learning_Lab_5_CNN_TL.ipynb
```

or open it directly in [Google Colab](https://colab.research.google.com/) / Kaggle (GPU
runtime strongly recommended - this notebook trains dozens of MobileNetV2 variants across
initialization, regularization, optimizer, hyperparameter, and cross-validation studies) and
run all cells top to bottom. The notebook fetches the dataset and pretrained ImageNet weights
itself - nothing needs to be downloaded by hand.
