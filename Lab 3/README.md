# Convolutional Neural Network - CIFAR-10 Image Classification

**CS3807 – Deep Learning Laboratory, Experiment 3 - Convolutional Neural Network**

A Convolutional Neural Network built with TensorFlow/Keras to classify natural images into 10
categories, using the CIFAR-10 dataset, followed by a study of pooling strategies and batch
size.

## Overview

This project covers the full pipeline end to end:

- Dataset exploration (sample images, class distribution)
- Preprocessing (pixel normalization to $[0,1]$, one-hot encoding, 45,000/5,000/10,000
  train/validation/test split)
- A 5-convolution-layer CNN built in Keras - three blocks of Conv2D $\to$ BatchNorm $\to$
  ReLU $\to$ MaxPooling, followed by Flatten $\to$ Dense(256, ReLU) $\to$ Dense(10, Softmax),
  with full epoch-by-epoch training logs
- Trainable-parameter analysis for every convolutional layer, manually verified against the
  standard parameter-count formula
- Training with data augmentation and a `ReduceLROnPlateau` learning-rate schedule
- Evaluation (accuracy, precision, recall, F1-score, confusion matrix, classification report)
- Feature map visualization across all five convolutional layers, showing the shift from
  low-level edges to sparse, high-level activations with depth
- A Max Pooling vs. Average Pooling comparison, and a batch-size comparison (32 vs. 128)

## Results

| Metric    | Value  |
|-----------|--------|
| Accuracy  | 85.27% |
| Precision | 85.53% |
| Recall    | 85.27% |
| F1-score  | 85.01% |

Trained for 30 epochs at batch size 64 (Adam, initial lr = 0.001, decayed via
`ReduceLROnPlateau`) on the full 45,000-image training set and evaluated on the 10,000-image
test set. Total model size: 668,842 trainable parameters (139,424 of which are in the
convolutional layers).

A separate, shorter comparison (10,000-image subset, 8 epochs) found Max Pooling
(55.48% test accuracy) modestly ahead of Average Pooling (54.55%), and batch size 32
(59.06%) clearly ahead of batch size 128 (54.60%) under identical conditions.

## Dataset

**CIFAR-10 Dataset** — University of Toronto, fetched programmatically via
`tensorflow.keras.datasets.cifar10`, so no manual download is required.

- 60,000 colour images total (50,000 train / 10,000 test), $32 \times 32$ pixels, RGB,
  10 object classes (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck)
- Classes perfectly balanced (5,000 training images per class)
- No missing values

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

```bash
jupyter notebook deep_learning_lab_3.ipynb
```

or open it directly in [Google Colab](https://colab.research.google.com/) (GPU runtime
recommended - the full 30-epoch training run takes roughly 15-20 minutes on a GPU) and run
all cells top to bottom. The notebook fetches the dataset itself - nothing needs to be
downloaded by hand.

## Building the Report

The LaTeX report lives in `report/main.tex` and pulls in the figures from `report/figures/`.
The figures are already PDF (not EPS), so no `-shell-escape` flag is required.

1. Upload `report/main.tex` and everything in `report/figures/` into an
   [Overleaf](https://www.overleaf.com/) project (same folder level - keep the `figures/`
   subfolder as is).
2. Compile with pdfLaTeX.

Or locally:

```bash
cd report
pdflatex main.tex
pdflatex main.tex
```
