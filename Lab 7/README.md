# End-to-End Study of Autoencoders, Convolutional Autoencoders, Denoising Autoencoders and Variational Autoencoders

**CS3807 – Deep Learning Laboratory, Experiment 7 - Autoencoders, CAE, Denoising AE and VAE on MNIST**

A single dataset, MNIST, used throughout to progressively build and compare a fully connected
autoencoder, a Convolutional Autoencoder (CAE), a denoising CAE, and a Variational Autoencoder
(VAE), finishing with latent-space visualization, image generation, and interpolation.

## Overview

This project covers the full pipeline end to end:

- Dataset loading via `tf.keras.datasets.mnist`, with a 10,000-image training subset and a
  2,000-image test subset (randomly sampled, seeded), normalized to $[0,1]$ and cached to
  Google Drive so the raw `.npz` is only ever downloaded once
- A Fully Connected Autoencoder (784→128→32→16→32→128→784) with required reconstruction
  plots, training/validation loss curves, and MSE/MAE/SSIM metrics
- A Convolutional Autoencoder (Conv2D/MaxPool/UpSampling2D stack) compared directly against
  the fully connected version on reconstruction quality and parameter count
- A Denoising CAE trained on Gaussian-corrupted inputs with the clean image as the target,
  evaluated across three noise levels ($\sigma=0.1,0.2,0.3$)
- A Variational Autoencoder (2D latent space) with the reparameterization trick, reconstruction
  + KL-divergence loss, latent-space visualization, random sample generation, and latent-space
  interpolation between two digits
- Reconstruction-error distribution and top-5 highest-error image analysis
- A latent-dimension study ($d_z\in\{2,8,16,32\}$) for both the fully connected and
  convolutional autoencoders
- All 25 discussion questions from the lab manual, answered directly
- All 8 additional exercises: CAE latent-dimension sweep, Gaussian vs. salt-and-pepper noise,
  two different denoising training noise levels, Conv2DTranspose vs. UpSampling2D, VAE with
  latent dim 2 vs. 8, effect of increasing the KL-loss weight, a larger VAE sample grid, and
  interpolation between a second pair of digit regions

## Results

| Model | MSE | MAE | SSIM | Parameters | Time (s) |
|-------|-----|-----|------|------------|----------|
| Fully Connected AE | 0.019970 | 0.054288 | 0.7735 | 211,040 | 16.14 |
| Convolutional AE | 0.002448 | 0.014828 | 0.9761 | 74,497 | 21.90 |
| Denoising CAE | 0.004572 | 0.021277 | 0.9475 | 74,497 | 20.00 |
| VAE | 0.053703 | 0.120811 | 0.3791 | 134,165 | 13.70 |

The Convolutional Autoencoder beat the Fully Connected Autoencoder decisively (SSIM 0.98 vs.
0.77) while using roughly a third of the parameters (74K vs. 211K) - keeping the image 2D
instead of flattening it to 784 values clearly mattered more than extra capacity. The Denoising
CAE held up well even at the highest tested noise level ($\sigma=0.3$, SSIM 0.88), still
recovering recognizable digit structure. The VAE's reconstruction metrics are well below the
plain CAE's by design - the KL term trades some reconstruction sharpness for a smooth,
continuous, generative latent space, which is exactly what let it generate new, plausible
digits from random noise and interpolate smoothly between two real ones. The latent-dimension
sweep showed most of the reconstruction-quality gain happens by $d_z=16$, with diminishing
returns afterward, for both the fully connected and convolutional versions.

## Dataset

**MNIST Handwritten Digit Dataset** — loaded via `tf.keras.datasets.mnist`, so no manual
download is required.

- Full set: 60,000 training images, 10,000 test images, each $28\times28\times1$ grayscale
- A recommended laboratory subset of 10,000 training images and 2,000 test images is randomly
  sampled (seeded) from the full set
- Pixels normalized from $[0,255]$ to $[0,1]$; flattened to $784$ for the fully connected
  autoencoder, kept as $28\times28\times1$ for every convolutional model
- Labels are never used as a reconstruction target - they are only used afterward, to color the
  VAE's 2D latent-space scatter plot

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the notebook

```bash
jupyter notebook Deep_Learning_Lab_7_Autoencoders_VAE.ipynb
```

or open it directly in [Google Colab](https://colab.research.google.com/) / Kaggle (GPU
runtime recommended - the notebook trains roughly 19 distinct models across the main pipeline,
the latent-dimension sweeps, and all 8 additional exercises) and run all cells top to bottom.
The notebook mounts Google Drive, downloads MNIST once, and caches it there - nothing needs to
be fetched by hand, and a later re-run skips the download entirely.

## Building the Report

The LaTeX report lives in `report/main.tex` and pulls in the figures from `report/figures/`.
The figures are already PDF (not EPS), so no `-shell-escape` flag is required.

1. Upload `report/main.tex` and everything in `report/figures/` into an
   [Overleaf](https://www.overleaf.com/) project (same folder level - keep the `figures/`
   subfolder as is).
2. Compile with pdfLaTeX.

Or locally:

```bash
cd report
pdflatex main.tex
pdflatex main.tex
```
